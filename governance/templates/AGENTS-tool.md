# AGENTS.md

本文件用于约束 AI 在本仓库中的修改范围。该项目属于低风险小型工具或展示项目，流程应保持轻量，但仍需提供可验证结果。

## 修改前

1. 阅读当前 Issue、PR、`README.md` 和相关测试；
2. 确认本次只解决一个主要问题；
3. 优先复用现有组件、工具和样式；
4. 区分已确认事实、推断和未验证行为。

## 实现规则

- 不直接推送正式主分支；
- 使用 `feat/*`、`fix/*`、`refactor/*`、`test/*`、`docs/*` 或 `chore/*` 分支；
- 不混合无关重构、依赖升级和功能修改；
- 不为小需求引入新的框架、状态管理或后端服务；
- 修改用户数据、导入导出、同步、Token 或跳转协议时提高风险等级并补充失败路径测试；
- 提交说明使用中文。

## 验证

根据项目实际命令执行：

- lint 或静态检查；
- 单元测试；
- 生产构建；
- 与变更相关的手动交互检查。

PR 必须说明实际执行结果、未执行项和剩余风险。不得把“应该可以”写成已验证。

## 合并

- 默认 squash merge；
- 合并后删除功能分支；
- CI 失败、存在冲突或有未解决审查意见时不得合并；
- 临时诊断 PR 应在验证后关闭，不合并无长期价值的诊断代码。

## 安全

- 不提交 Token、密码、密钥、Cookie 和生产配置；
- 外部 URL、导入文件、同步响应和 AI 输出均视为不可信输入；
- 删除、覆盖和批量操作必须有明确提示与边界；
- 不开放脚本执行、本地资源或其他危险协议，除非项目目标明确要求且有安全设计。
